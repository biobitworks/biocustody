# Agent operating rules

1. Use only public/synthetic/de-identified hackathon-admissible data.
2. Never place secrets in source files, FCO payloads, logs, or slides.
3. Never commit production private keys, developer private keys, encrypted production keys, seed phrases, API tokens, or cloud credentials. Only public keys, public-key fingerprints, placeholders, generated test keys, or fixtures clearly marked test/example are allowed.
4. Preserve original molecular representation as a custody leaf.
5. A derived SMILES does not erase BILN/HELM provenance.
6. Keep scientific evidence separate from licensing, patent, exclusivity, and FTO status.
7. Do not call independent perturbation opposition "measured rescue".
8. Do not call Bio-ΔG* physical Gibbs free energy.
9. Missing external adapters are `not_configured`, never PASS.
10. Deterministic calculation must be reproducible before adding an LLM explanation.
11. Every judge-facing metric must be computed, not invented.
12. Neptune and CompuCell3D are stretch lanes; do not let them block P0.
